ressumo-lab6
A ferramenta Language Studio do Azure oferece uma vasta gama de soluções para o trabalho com texto. Entre elas, destacam-se a análise textual para reconhecimento de frases-chave e análise de sentimentos; a criação de chatbots avançados, capazes de responder a consultas e interpretar com precisão a fala do interlocutor; a compreensão da linguagem coloquial, abrangendo declaração, entidade e intenção; e o reconhecimento e a síntese de fala, que permitem gerar voz a partir de texto ou o inverso.

No Azure, a ferramenta de síntese de fala está disponível no site speech.microsoft.com/portal.

Para criar um novo recurso de fala, acesse a aba 'Recurso' e, em seguida, clique em 'Criar novo recurso'. Uma janela será aberta, solicitando o nome do novo recurso, a assinatura, a região, o tipo de preço e o grupo de recursos.

Após a criação do recurso, selecione-o. Na tela de conversão de fala em texto, escolha a opção de conversão de texto em tempo real, selecione o idioma e o arquivo a ser convertido.

Em seguida, no laboratório, aprendemos a criar um recurso de idioma para análise de texto. Para isso, acesse o Language Studio e clique em 'Criar um idioma'. Os campos para preenchimento dos dados do recurso a ser criado serão exibidos, até a última aba de revisão e criação.

No Language Studio, selecione o recurso recém-criado e, em seguida, 'Criar novo recurso'. Selecione a opção de classificação de texto. Após o carregamento do texto, é possível observar a análise realizada.
